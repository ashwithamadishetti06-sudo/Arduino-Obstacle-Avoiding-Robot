# Arduino Obstacle Avoiding Robot

## About the Project
This project uses an Arduino to detect obstacles and change the robot's movement to avoid collisions.

## Components Used
- Arduino Uno
- HC-SR04 Ultrasonic Sensor
- IR Sensors
- L298N Motor Driver
- DC Motors
- Robot Chassis
- Battery
- Jumper Wires

## Working
1. The ultrasonic sensor measures the distance to an obstacle.
2. Arduino processes the sensor readings.
3. The L298N motor driver controls the motors.
4. When an obstacle is detected, the robot changes direction.

## Technologies Used
- Arduino Programming (C/C++)
- Embedded Systems
- Sensor Interfacing
- Motor Control
